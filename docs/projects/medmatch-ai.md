## Overview

MedMatch AI is an educational full-stack heart disease risk assessment app. Users enter patient vitals in a React form; a FastAPI backend scores risk with a Random Forest classifier trained on UCI/Kaggle heart-disease data, then returns prediction probability plus urgency, doctor advice, and lifestyle tips generated by rule-based logic tied to cholesterol, blood pressure, fasting sugar, angina, age, and heart rate. The project demonstrates end-to-end ML serving — train/export artifacts, REST inference, and a clear results UI — and is **not** a medical device for real clinical decisions.

## Challenges and solutions

1. **Feature alignment at inference** — One-hot columns must match training. Solution: persist `feature_columns.pkl` and align/encode request features before scaling.
2. **Explainable outputs** — Raw model scores alone are hard to act on. Solution: keep recommendations rule-based so each tip maps to a concrete input threshold (e.g. chol > 240).
3. **Local full-stack DX** — Separate Vite and FastAPI ports need CORS. Solution: CORS-enabled FastAPI for local Vite development.
4. **Educational safety** — Risk of users treating the demo as clinical advice. Solution: explicit disclaimer that MedMatch AI is not a medical device.
